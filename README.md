# Cesar Alexander's Personal Portfolio

This repository contains the source code for my personal developer portfolio, accessible at [cesaralexander.dev](https://cesaralexander.dev/).

It is designed to showcase my background in Computer Science, my experience as a Data Engineer Intern at Grupo DEACERO, and my web development projects.

## Tech Stack

This project is built using modern web technologies to ensure high performance, SEO optimization, and a great developer experience.

* **Framework:** [Astro 5.0](https://astro.build/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Language:** TypeScript / JavaScript
* **Deployment:** [Your Hosting Provider, e.g., Vercel / Netlify]

## Prerequisites

Before you begin, ensure you have the following installed on your local machine:
* **Node.js** (v18.14.1 or higher is recommended for Astro)
* **npm** (or your preferred package manager like `pnpm` or `yarn`)

## Running Locally

To run this project on your local machine, follow these steps:

**1. Clone the repository**

git clone [https://github.com/cesaralexanderds/portfolio.git](https://github.com/cesaralexanderds/portfolio.git)
cd portfolio

**2. Install dependencies**

npm install

**3. Start the development server**
npm run dev

**4. Open in your browser**
Navigate to http://localhost:4321 to view the site. The development server will automatically reload when you make changes to the code.
